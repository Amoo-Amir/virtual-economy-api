# Virtual Economy Backend

یک API بک‌اند برای مدیریت اقتصاد مجازی یک بازی یا پلتفرم دیجیتال. کاربران می‌توانند حساب ایجاد کنند، موجودی کیف پول خود را مدیریت کنند، آیتم‌های مجازی را در مارکت‌پلیس بفروشند یا خریداری کنند و تاریخچه تراکنش‌های خود را مشاهده کنند.

این پروژه با Node.js و Express توسعه داده شده و از PostgreSQL برای ذخیره‌سازی اطلاعات و Prisma ORM برای ارتباط با دیتابیس استفاده می‌کند.

> این پروژه صرفاً برای مدیریت دارایی‌های مجازی طراحی شده و هیچ پرداخت یا انتقال پول واقعی در آن انجام نمی‌شود.

## امکانات

- ثبت‌نام و ورود کاربران
- احراز هویت با JWT
- مدیریت کیف پول و موجودی کاربران
- انتقال اعتبار بین کاربران
- مشاهده تاریخچه تراکنش‌ها
- مدیریت آیتم‌های مجازی
- مشاهده و جست‌وجوی آیتم‌ها با صفحه‌بندی
- ایجاد آگهی فروش در مارکت‌پلیس
- خرید و لغو آگهی‌های فروش
- مشاهده سفارش‌ها، فروش‌ها و آگهی‌های شخصی
- اعتبارسنجی ورودی‌ها
- مدیریت متمرکز خطاها
- مستندات API با Swagger
- تست خودکار با Jest و Supertest
- اجرای پروژه با Docker Compose

## معماری پروژه

ساختار بک‌اند بر اساس جداسازی مسئولیت‌ها طراحی شده است:

```text
Router → Controller → Service → Repository
```

- **Router:** تعریف مسیرها و اتصال Middlewareها
- **Controller:** دریافت درخواست و ارسال پاسخ HTTP
- **Service:** پیاده‌سازی منطق اصلی برنامه
- **Repository:** ارتباط با دیتابیس از طریق Prisma

این ساختار باعث می‌شود منطق برنامه از جزئیات HTTP و دسترسی به دیتابیس جدا بماند.

## دیتابیس و تراکنش‌ها

PostgreSQL برای ذخیره اطلاعات کاربران، کیف پول‌ها، آیتم‌ها، موجودی کاربران، آگهی‌ها، سفارش‌ها و تراکنش‌ها استفاده شده است.

در بخش مارکت‌پلیس، عملیات خرید در قالب تراکنش دیتابیس انجام می‌شود تا تغییرات مرتبط با موجودی خریدار، موجودی فروشنده، سفارش، آگهی و دفترکل تراکنش‌ها با یکدیگر هماهنگ باشند.

همچنین از تراکنش‌های Serializable و به‌روزرسانی‌های شرطی برای کاهش احتمال مشکلات هم‌زمانی مانند خرید تکراری یک آگهی یا خرج‌شدن هم‌زمان موجودی استفاده شده است.

## مستندات API

پس از اجرای پروژه، مستندات Swagger از مسیر زیر در دسترس هستند:

```text
http://localhost:3000/api-docs
```

در Swagger می‌توان endpointها، پارامترها، پاسخ‌ها و نیازمندی احراز هویت را بررسی و درخواست‌ها را مستقیماً اجرا کرد.

## راه‌اندازی پروژه

### پیش‌نیازها

- Docker
- Docker Compose

برای اجرای نسخه کانتینری، نیازی به نصب جداگانه Node.js یا PostgreSQL روی سیستم میزبان نیست.

### ۱. دریافت پروژه

```bash
git clone <repository-url>
cd wallet
```

### ۲. تنظیم متغیرهای محیطی

یک فایل `.env` در ریشه پروژه ایجاد کنید و متغیرهای موردنیاز پروژه و Docker Compose را در آن قرار دهید.

مقادیر اتصال دیتابیس، اطلاعات احراز هویت و سایر تنظیمات محرمانه باید در این فایل تعریف شوند.

**فایل `.env` نباید در Git منتشر شود.**

### ۳. اجرای پروژه

```bash
docker compose up -d --build
```

Docker Compose سرویس‌های API و PostgreSQL را اجرا می‌کند. پس از آماده‌شدن دیتابیس، Migrationهای Prisma اعمال شده و API راه‌اندازی می‌شود.

### ۴. بررسی وضعیت سرویس

```bash
docker compose ps
```

بررسی سلامت API:

```bash
curl http://localhost:3000/health
```

پاسخ موفق باید وضعیت API و اتصال دیتابیس را نشان دهد.

### ۵. مشاهده مستندات

```text
http://localhost:3000/api-docs
```

## اجرای تست‌ها

برای اجرای تست‌ها در محیط توسعه:

```bash
npm test
```

تست‌ها با Jest و Supertest اجرا می‌شوند و بخش‌هایی از منطق برنامه، APIها، اعتبارسنجی و رفتار تراکنش‌ها را بررسی می‌کنند.

## API Endpoints

مسیرهای اصلی API:

| Method | Endpoint | توضیحات |
|---|---|---|
| GET | `/health` | بررسی سلامت سرویس |
| POST | `/api/auth/register` | ثبت‌نام |
| POST | `/api/auth/login` | ورود |
| GET | `/api/auth/profile` | پروفایل کاربر فعلی |
| GET | `/api/auth/{userId}` | دریافت اطلاعات کاربر |
| GET | `/api/wallet/myWallet` | کیف پول‌های کاربر |
| POST | `/api/wallet/resolve-card` | شناسایی گیرنده انتقال |
| POST | `/api/wallet/transfer` | انتقال اعتبار |
| GET | `/api/transactions` | تاریخچه تراکنش‌ها |
| GET | `/api/items` | فهرست آیتم‌ها |
| GET | `/api/inventory/myINV` | موجودی آیتم‌های کاربر |
| GET | `/api/market/listings` | مشاهده آگهی‌ها |
| POST | `/api/market/listings` | ایجاد آگهی |
| POST | `/api/market/listings/{listingId}/purchase` | خرید آگهی |
| POST | `/api/market/listings/{listingId}/cancel` | لغو آگهی |
| GET | `/api/market/my-listings` | آگهی‌های کاربر |
| GET | `/api/market/my-orders` | سفارش‌های کاربر |
| GET | `/api/market/my-sales` | فروش‌های کاربر |

برای مشاهده جزئیات ورودی‌ها، خروجی‌ها و پاسخ خطاها، از Swagger استفاده کنید.
